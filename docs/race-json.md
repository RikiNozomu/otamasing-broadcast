# รูปแบบไฟล์ JSON ของรายการแข่ง

ไฟล์นี้ใช้ทั้งตอน **นำเข้า JSON** และ **ส่งออก** ใน dock ถ้าจะให้ Claude แปลงข้อมูลจากหน้าเว็บ (เช่น netkeiba) ให้แปะเอกสารนี้ หรือ [`schema/race.schema.json`](../schema/race.schema.json) ไปด้วย แล้วบอกว่า "แปลงเป็น JSON ตามรูปแบบนี้"

- ไฟล์ทั้งไฟล์ต้องเป็น object ที่มี `races` (อาร์เรย์ของรายการ) หรือจะเป็นอาร์เรย์ของรายการเฉยๆ ก็ได้
- ช่องที่ไม่ใส่จะใช้ค่าเริ่มต้นในตาราง ช่องที่ **ต้องมี** มีแค่ `date`, `name` และ `runners`
- ตอนนำเข้าเลือกได้ว่าจะ **เพิ่มต่อ** (รายการที่ วัน + สนาม + เลขรอบ ตรงกับของเดิมจะถูกแทนที่) หรือ **แทนที่ทั้งหมด**
- รูป (รูปด้านซ้ายของการ์ด, BG หน้าแรก) ไม่อยู่ในไฟล์ ต้องเลือกใหม่ในเครื่องที่ใช้

ตัวอย่างเต็มอยู่ที่ [`example-race.json`](example-race.json)

## ระดับไฟล์

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `version` | `1` | `1` | รุ่นของรูปแบบไฟล์ |
| `races` | อาร์เรย์ของรายการ | (ต้องมี) | รายการแข่ง เรียงตามลำดับที่จะแสดงในหน้าแรก |
| `home` | object | – | ค่าของหน้าแรก: `title`, `subtitle` (วันที่), `highlight` (id ของรายการที่ไฮไลต์ หรือ `null`) |
| `active` | string | – | สิ่งที่ขึ้นจอ (ใช้ตอนแทนที่ทั้งหมด): `"home"` หน้าแรก, `"blank"` หน้าเปล่า, `id` ของรายการ (การ์ดรายชื่อม้า) หรือ `"<id>:result"` (หน้าผลของรายการนั้น) |
| `transition` | `"wipe"` `"slide"` `"fade"` `"none"` | – | ทรานซิชันตอนเปลี่ยน Active |

## รายการ (`races[]`)

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `id` | string | สร้างให้ | ใส่เองไม่จำเป็น |
| `date` | `"YYYY-MM-DD"` | (ต้องมี) | วันแข่ง |
| `course` | string | `""` | สนาม เช่น `"Tokyo"` |
| `round` | string | `""` | เลขรอบ พิมพ์อะไรก็ได้ เช่น `"11R"`, `"R11"`, `"Main"` |
| `postTime` | string | `""` | เวลาออกตัว เช่น `"15:40"` |
| `name` | string | (ต้องมี) | ชื่อรายการ (ภาษาอังกฤษ ขึ้นเป็นตัวใหญ่บนการ์ด) |
| `jpName` | string | `""` | ชื่อภาษาญี่ปุ่นบรรทัดบน เช่น `"第86回 菊花賞"` |
| `subtitle` | string | `""` | บรรทัดรองใต้ชื่อ |
| `grade` | `"G1"` `"G2"` `"G3"` `"L"` หรือ `null` | `null` | เกรด (`"L"` = Listed) |
| `jump` | boolean | `false` | รายการวิบาก (ป้ายเกรดขึ้นต้น `J-`) |
| `class` | `"2YO"` `"2YO_F"` `"3YO"` `"FM"` หรือ `null` | `null` | ป้าย Class: 2YO (ฟ้า), 2YO ตัวเมีย (ชมพู), 3YO (ฟ้า), F&M (ชมพู) |
| `surface` | `"Turf"` `"Dirt"` `"Jump"` | `"Turf"` | พื้นสนาม |
| `distanceM` | จำนวนเต็ม หรือ `null` | `null` | ระยะ (เมตร) |
| `highlight` | จำนวนเต็ม หรือ `null` | `null` | เบอร์ม้าที่ไฮไลต์บนการ์ด |
| `style` | object | ค่าเริ่มต้นด้านล่าง | สไตล์ของรายการนี้ (ใช้กับหน้าผลด้วย) |
| `result` | object | `{ "page": 0, "locked": [] }` | หน้าผล: `page` หน้าที่แสดง (เริ่มที่ 0), `locked` เบอร์ม้าที่ล็อคไว้บนสุดทุกหน้า (สูงสุด 9 ตัว) |
| `runners` | อาร์เรย์ 2–30 ตัว | (ต้องมี) | ม้า เบอร์ห้ามซ้ำ |

## ม้า (`runners[]`)

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `number` | 1–30 | (ต้องมี) | เบอร์ม้า (NO.) |
| `draw` | 1–30 หรือ `null` | `null` | ซอง ใช้เมื่อปิด "คำนวณซองอัตโนมัติ" (ถ้าเปิดไว้ จะคิดซองจากเบอร์ตามกฎ JRA) |
| `name` | string | `""` | ชื่อม้า |
| `jockey` | string | `""` | ชื่อจ็อกกี้ |
| `horseCountry` | รหัสประเทศ 2 ตัว หรือ `""` | `""` | ธงหน้าชื่อม้า |
| `jockeyCountry` | รหัสประเทศ 2 ตัว หรือ `""` | `""` | ธงหน้าชื่อจ็อกกี้ |
| `fav` | 1–30 หรือ `null` | `null` | อันดับตัวเต็ง (ขึ้นป้าย 1st, 2nd, …) |
| `scratched` | boolean | `false` | ถอนตัว (ขีดฆ่า จางลง) |
| `finish` | 1–30 หรือ `null` | `null` | อันดับที่เข้าเส้นชัย (`null` = ยังไม่มีผล หรือไม่เข้าเส้นชัย ไม่ขึ้นหน้าผล) เข้าพร้อมกันใส่เลขซ้ำได้ |
| `time` | string | `""` | เวลาที่ทำได้ เช่น `"2:24.1"` |
| `margin` | string | `""` | ระยะห่างจากตัวข้างหน้า เช่น `"1¼"`, `"½"`, `"nk"`, `"hd"`, `"nse"` (ตัวชนะเว้นว่าง) |

รหัสประเทศเป็น ISO 3166 แบบ 2 ตัวอักษร ชุดที่ dock มีให้เลือก (ตรงกับ component "flag" ใน Figma) คือ
`JP` ญี่ปุ่น, `AR` อาร์เจนตินา, `IT` อิตาลี, `BE` เบลเยียม, `US` สหรัฐฯ, `HK` ฮ่องกง, `PR` เปอร์โตริโก, `BB` บาร์เบโดส, `IE` ไอร์แลนด์, `DE` เยอรมนี, `PA` ปานามา, `GB` สหราชอาณาจักร, `FR` ฝรั่งเศส, `VE` เวเนซุเอลา, `AU` ออสเตรเลีย, `NZ` นิวซีแลนด์, `DO` โดมินิกัน, `CA` แคนาดา, `AE` สหรัฐอาหรับเอมิเรตส์, `MX` เม็กซิโก, `ZA` แอฟริกาใต้, `CL` ชิลี, `PE` เปรู
รหัสอื่นก็ใช้ได้ (ธงมาจาก flag-icons ครบทุกประเทศ) แค่ไม่อยู่ในตัวเลือกของ dock

## หน้าผลการแข่งขัน

หน้าผลแสดง POS, NO., DRAW (ถ้าเปิดไว้), HORSE, JOCKEY, TIME, MARGIN ได้สูงสุด 10 แถว เรียงตาม `finish`
ม้าที่ล็อค (`result.locked`) อยู่บนสุดทุกหน้าพร้อมแถบเหลือง แถวที่เหลือเปลี่ยนตามหน้า เช่น มีผล 17 ตัวและล็อค 3 อันดับแรก:
หน้า 1 = อันดับ 1–3 + 4–10, หน้า 2 = อันดับ 1–3 + 11–17

## สไตล์ (`style`)

| ช่อง | ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `drawScheme` | `"jra"` `"us"` `"plain"` `"custom"` | `"jra"` | สีช่อง DRAW: JRA 8 สี, saddle towel อเมริกา, กรอบขาว, กำหนดเอง |
| `numberScheme` | เหมือนด้านบน | `"plain"` | สีช่อง NO. (`"jra"` = สีตามซองของม้า) |
| `autoDraw` | boolean | `true` | คิดซองให้จากเบอร์ตามกฎ JRA (เกิน 8 ตัว ม้าที่เกินไปอยู่ซองท้ายๆ ก่อน) |
| `gradeStyle` | `"jra"` `"intl"` | `"jra"` | ป้ายเกรดแบบ GI/GII/GIII/LR หรือ G1/G2/G3/L |
| `show` | object ของ boolean | ทุกช่อง `true` | `draw`, `grade`, `class`, `fav`, `horseFlag`, `jockeyFlag`, `jpName` |
| `customColors` | `{ "1": ["#พื้น", "#ตัวเลข"], … }` | `{}` | สีของชุด Custom ต่อเบอร์ เบอร์ที่ไม่ใส่ใช้สีอเมริกา |
